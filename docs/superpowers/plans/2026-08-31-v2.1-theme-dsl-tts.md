# v2.1 Theme Visual DSL and Executable TTS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release v2.1.0 with a bounded topic-specific visual DSL and executable, authorized, recoverable TTS adapters while preserving v2.0 project and release compatibility.

**Architecture:** A new `visual-dsl.mjs` validates and compiles semantic scene programs into escaped DOM/SVG plus deterministic cue-relative actions consumed by the existing renderer. A new `voice-adapters.mjs` owns the reviewed adapter registry, authorization checks, per-cue cache, audio normalization, measured timing, and trusted host-command protocol; declarative extensions remain non-executable.

**Tech Stack:** Node.js 22 ESM, Node test runner, HTML/CSS/SVG, deterministic browser timelines, Python `edge-tts` as an optional host dependency, FFmpeg/ffprobe, HyperFrames, Hatch/Twine, npm, PyPI, GitHub Actions/Releases.

**Spec:** `docs/superpowers/specs/2026-08-31-v2.1-theme-dsl-tts-design.md`

## Global Constraints

- Package version is exactly `2.1.0` across npm, PyPI, runtime metadata, changelog, release notes, and generated manifests.
- Node.js runtime minimum remains `22`.
- Declarative Extension API remains version `1` and continues rejecting hooks, scripts, and postinstall fields.
- Visual programs cannot contain raw HTML, JavaScript, shell commands, remote URLs, data URIs, or asset paths outside project `assets/`.
- Captions and TTS use one canonical normalized string; spoken text contains no underscore.
- Uncached network synthesis requires `--allow-network`; paid or unknown-cost synthesis also requires `--authorize-provider-cost`.
- Credentials never enter project files, adapter request JSON, process arguments generated from secrets, logs, manifests, or release artifacts.
- `fixture-tts` output is test-only and cannot satisfy the real-audio stage gate.
- Real measured narration timing remains the final animation clock.
- Automated evidence stops at `release_candidate_pending_human_listen`; no test or provider success implies publication approval.
