# Spatial Chamber

Use when the explanation depends on location, route, layers, transfer, queues, or several components acting in sequence. Put one state-changing object on an intentional path through a spatial system instead of stacking interchangeable cards.

Depth and camera movement must encode knowledge: foreground establishes the current state, the mid-ground shows transformation, and the background previews destination or consequence. Keep labels facing the viewer, protect caption and title safe areas, and use static SVG path sampling when premium motion plugins are unavailable.
