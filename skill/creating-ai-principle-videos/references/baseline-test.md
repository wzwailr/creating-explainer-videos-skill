# Baseline control test

## Scenario

Without this skill, an agent was asked to specify a 5–6 minute Chinese AI-principle video on speculative decoding with synchronized captions and a publish package.

## Observed control behavior

The control produced a competent generic contract, but it:

- targeted about 1250–1450 Chinese characters instead of the series' 1700–2200 deep-episode baseline;
- did not require the first sentence to connect the previous episode and name the current topic;
- did not require the final sentence to name the next topic and its value;
- allowed subtitles that were merely semantically consistent instead of character-identical to TTS from one source;
- did not make real narration timing the sole animation clock;
- omitted the title/card/narration/focus semantic contract;
- omitted the spoken-underscore failure guard;
- omitted A/C visual grammar, DingTalk font roles, and deterministic paused GSAP timelines;
- omitted the ban on repeated full-canvas scanning edges;
- omitted the dedicated series/season/episode cover hierarchy and clean top-right rule;
- invented a different release-state vocabulary.

These gaps are the reason the skill carries explicit non-negotiable rules and executable validation rather than only general production advice.
